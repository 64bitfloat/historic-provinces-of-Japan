# GeoAnki 68 — 全国令制国・旧国名 視覚ベクター暗記トレーナー 🗾

日本の律令制に基づく令制国（五畿七道68国：武蔵・信濃・尾張・薩摩など）を、美麗なダークテーマ白地図ベクターポリゴンで直観的に暗記できるSPA Webアプリケーションです。

GeoGuessrでの地域絞り込みや日本史・地理学習の特訓ツールとして最適化されています。

🌐 **Webアプリ**: [https://64bitfloat.github.io/historic-provinces-of-Japan/](https://64bitfloat.github.io/historic-provinces-of-Japan/)

---

## ✨ 主な特徴

- 🗺️ **五畿七道 68国完全網羅**
  - 畿内（5国）、東海道（15国）、東山道（8国）、北陸道（7国）、山陰道（8国）、山陽道（8国）、南海道（6国）、西海道（11国）
  - 各国に「読み仮名」「現代の都道府県」「代表的な名所・特徴ヒント」を網羅。
- 🎯 **4つの特訓モード**
  1. **📍 場所当てモード**: 「『武蔵（むさし）』はどこ？」という出題に対し、地図上のポリゴンを直接タップして回答。
  2. **🏷️ 名前当てモード**: 地図上で点滅する旧国名を4択ボタンから選択（キーボード `[1]` `[2]` `[3]` `[4]` 対応）。
  3. **⌨️ 入力モード**: 点滅する旧国名をキーボード（ひらがな/漢字）で入力。
  4. **🔍 探索モード**: 地図上のポリゴンを自由にタップして、旧国名・ふりがな・現代の地域・名所・成績を閲覧。
- ⭐ **4段階ステップアップ ＆ 苦手克服デッキ**
  - **Lv.1**: 武蔵・信濃・尾張・薩摩など超有名・必修の15国
  - **Lv.2**: 三河・美濃・伊勢・越前など基本の21国
  - **Lv.3**: 遠江・但馬・備中・肥前など差がつく24国
  - **Lv.4**: 志摩・若狭・隠岐・対馬など難関の8国
  - **⚡ 苦手克服**: 直近で間違えた国だけを抽出して自動集中復習。
- ⚡ **完全スタンドアロン & 爆速ロード**
  - 68国の境界GeoJSONポリゴンを最適化してインライン内蔵。
  - 外部通信待ち時間ゼロで即座に起動、オフライン環境でも動作可能。
- 🔊 **Web Audio API による効果音シンセサイザー**
  - 正解チャイム・不正解ブザー（外部音声ファイル読み込み不要、オン/オフ切り替え可）。
- 📱 **レスポンシブ & モバイル完全最適化**
  - スマホの縦画面タッチ操作、タブレット、PCの大画面まで快適に操作可能。

## 🛠️ 技術スタック

- **フロントエンド**: HTML5, Vanilla JavaScript, Tailwind CSS (CDN)
- **地図レンダラー**: Leaflet.js (Vector GeoJSON Polygon)
- **データ処理**: Python (ArcGIS Online FeatureServer 由来の令制国境界データの最適化・結合)
- **効果音**: Web Audio API (Sine / Sawtooth Wave Synthesizer)
- **永続化**: Web Storage (LocalStorage)

## 🚀 ビルド & 開発方法

リポジトリ内の `index.html` 単体でブラウザからそのまま開いて実行可能です。

データを再構築・再生成したい場合:
```bash
# 1. データのダウンロードと最適化
python prepare_data.py

# 2. index.html のビルド
python build_app.py
```
